# Security

GPUfit accepts private vulnerability reports on GitHub.

Report a vulnerability here: [github.com/nish17/gpufit/security/advisories/new](https://github.com/nish17/gpufit/security/advisories/new)

That page works after private vulnerability reporting is enabled for the repository (Settings → Advanced Security → Private vulnerability reporting). Please include the page or endpoint, what you expected, and what happened. Do not open a public issue for an unfixed vulnerability, and do not include subscriber data or secret values.

`alerts@gpufit.tech` is a sending address for alert mail. The domain has no mail exchanger, so do not use it as a security contact.
